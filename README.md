# Ask Your PDFs (RAG)

A small Retrieval-Augmented Generation app: it indexes a folder of PDFs and answers questions about them with page-level citations like `[nist-ai-rmf.pdf, p. 25]`. If the answer is not in the documents, it says **"I don't know based on the provided documents."**

```
                 ingest.py                                       ask.py / app.py
PDFs ─► text per page ─► overlapping chunks ─► embeddings ─► Chroma ─► top-k search ─► LLM ─► answer + [file, p. N]
       (pypdf)          (~800 chars, 150 overlap)  (bge-small)          (cosine)       (Gemini / OpenAI / Claude)
```

## Tech stack

| Part | Choice | Why |
| --- | --- | --- |
| PDF → text | `pypdf` | Pure Python, gives text page by page, so every chunk knows its page number. |
| Embeddings | `sentence-transformers` with `BAAI/bge-small-en-v1.5` | Small (33M params), runs on CPU, much better retrieval than `all-MiniLM-L6-v2` (that model could not match "SBERT" to the Sentence-BERT paper). |
| Vector store | Chroma (persistent, local folder `chroma_db/`) | No server needed; stores text + `source` + `page` metadata. |
| LLM | Gemini, OpenAI or Anthropic — whichever API key is set | Gemini has a free tier. |
| UI | CLI (`ask.py`) and Streamlit web UI (`app.py`) | |

## Setup

Requires Python 3.10–3.12.

```bash
python -m venv .venv
# Windows (PowerShell):  .venv\Scripts\Activate.ps1
# macOS / Linux:         source .venv/bin/activate
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and set **one** API key (e.g. `GEMINI_API_KEY`, free at <https://aistudio.google.com/apikey>).

Build the index (first run downloads the ~130 MB embedding model):

```bash
python ingest.py
```

```
  chain-of-thought.pdf: 43 pages -> 230 chunks
  nist-ai-rmf.pdf: 48 pages -> 192 chunks
  self-rag.pdf: 30 pages -> 179 chunks
  sentence-bert.pdf: 11 pages -> 73 chunks
Indexed 674 chunks from 4 PDFs into ...\chroma_db
```

To use your own documents, put PDFs into `pdfs/` (or set `PDF_DIR`) and run `python ingest.py` again; it rebuilds the index from scratch.

## Asking questions

CLI, one question:

```bash
python ask.py "What are the four functions of the AI RMF Core?"
```

```
The four functions of the AI RMF Core are GOVERN, MAP, MEASURE, and MANAGE [nist-ai-rmf.pdf, p. 25].
```

CLI, interactive mode: `python ask.py`. Add `--show-context` to see the retrieved chunks and their similarity scores, `-k 8` to retrieve more chunks.

Web UI:

```bash
streamlit run app.py
```

Opens <http://localhost:8501> with a question box, a top-k slider and an expandable list of the retrieved excerpts.

## How it works

**Ingestion** ([rag/ingest.py](rag/ingest.py))
1. Each PDF page is extracted separately with pypdf and cleaned: Unicode NFKC (turns ligatures like "ﬁ" into "fi"), words hyphenated at line ends are re-joined, whitespace is collapsed.
2. Each page is split into chunks of ~800 characters on sentence boundaries; every chunk starts with the last ~150 characters of the previous one (overlap), so a sentence cut at a chunk border is still found. Chunks never cross pages, so each chunk has exactly one page to cite.
3. Chunks are embedded with bge-small (normalized vectors) and stored in Chroma with metadata `{source: filename, page: N}`.

**Retrieval** ([rag/store.py](rag/store.py)): the question (with bge's query instruction prefix) is embedded and the top-k (default 5) chunks by cosine similarity are returned.

**Generation** ([rag/answer.py](rag/answer.py))
- Each chunk goes into the prompt with a header like `### Excerpt 2 [self-rag.pdf, p. 1]`. The system prompt tells the model to use only those excerpts, end every factual sentence with a citation copied from a header, and reply with the exact "I don't know..." sentence when the excerpts don't contain the answer.
- "I don't know" has two layers: if even the best chunk has similarity below `MIN_SIMILARITY` (0.5), the LLM isn't called at all; otherwise the LLM decides based on the prompt rules.
- Citations in the answer are checked against the retrieved chunks; a citation that wasn't retrieved (hallucinated) is shown as a warning.

## Limitations

- Scanned PDFs (images without a text layer) are skipped; they would need OCR.
- Tables and figures come out of pypdf as flat text, so numbers inside charts are retrieved less reliably.
- The similarity threshold is tuned for bge-small; with another embedding model, check the scores with `--show-context` and adjust `MIN_SIMILARITY`.
